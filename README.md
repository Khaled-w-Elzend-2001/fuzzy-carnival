# Samar's portfolio

Open `index.html` in your browser. This is plain HTML and CSS: no installation or build step is needed.

## Add Samar's images

Replace the nine labeled placeholder PNGs in this folder with the actual images, keeping these exact filenames:

- `profile_pic.png` — Samar's portrait
- `wor1.png`, `wor2.png`, `wor3.png`, `wor4.png`
- `wor5.png`, `wor6.png`, `wor7.png`, `wor8.png`

The included PNGs are neutral placeholders, not Samar's artwork. If your files are JPEGs, change the matching filenames in `index.html`; simply changing a file extension does not convert its format.

Replace the Lorem ipsum paragraphs, artwork titles, and image `alt` descriptions in `index.html` with her own words. Artwork images use `object-fit: contain` so the whole painting remains visible. Clicking an artwork opens its original image.

## Styling

Edit `styles.css`. The design uses Cormorant Garamond italic for classical headings and Great Vibes for Samar's signature. Google Fonts loads these when online; Baskerville, Palatino, or Georgia provide offline fallbacks. The generated balcony painting is a decorative background, not part of Samar's portfolio.

The layout includes a left portrait, smooth scrolling to the biography, eight artworks, responsive sizing, keyboard focus states, and reduced-motion support. No JavaScript is required.
